# Bidrag og arbejdsform

Projektet er indtil videre et privat hobbyprojekt. Ændringer skal stadig være sporbare og reviewbare.

## Branch og commits

- Branch: `feature/PO-###-kort-navn`, `fix/PO-###-kort-navn` eller `docs/PO-###-kort-navn`.
- Commit: `PO-###: kort imperativ beskrivelse`.
- Én backlog-story pr. PR, medmindre to stories ikke kan valideres separat.

## Før en PR

- Acceptance criteria er opfyldt.
- Relevante tests er tilføjet eller opdateret.
- Dokumentation og ADR er opdateret ved arkitekturændringer.
- Ingen private assets, credentials eller signing keys er staged.
- Devicepåstande er markeret som målt, dokumenteret eller antaget.

## Definition of done

En feature er ikke færdig, før den er demonstreret på det relevante fysiske headset og dens netværks-, save- og performancekonsekvenser er vurderet.
