# M0 platform feasibility spike

Der må først oprettes et rigtigt Unity-projekt i denne mappe, når Claude-reviewets blockere er behandlet.

M0 skal bevise:

1. samme gameplaykode og scenarioformat på Quest 2 og Quest 3,
2. controllertracking, grab og comfort locomotion,
3. privat Photon-session med compatibility handshake,
4. head/hand replication,
5. fælles kinematic tung-kasse-interaktion,
6. signeret APK og BuildInfo,
7. 72 Hz i minimal scene på alle tre enheder,
8. dokumenteret package/graphics API matrix.

Hvis én package lock ikke kan starte på alle enheder, må kun manifests/lockfiles og platformadapters divergere. Gameplay, protocol, content og save schema skal fortsat være fælles.
