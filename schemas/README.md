# Data contracts

JSON Schema-filerne beskriver de logiske kontrakter, som senere skal implementeres som Unity ScriptableObjects/runtime snapshots.

Kør `python tools/validate_handoff.py` for at validere alle eksempler. Skemaerne er reviewgrundlag og kan ændres efter Claude-reviewet, men IDs og save-breaking ændringer skal derefter spores i ADR- og migrationslog.
