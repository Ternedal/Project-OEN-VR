# Claude review checklist

- [ ] Executive verdict valgt.
- [ ] Top 10 fund har stabile CR-ID'er.
- [ ] Quest 1/2/3-påstande har kilder eller er markeret som antagelser.
- [ ] Dokumentkonflikter har CONFLICT-ID'er.
- [ ] Multiplayer authority, reconnect og save er reviewet.
- [ ] Scope og timer er udfordret realistisk.
- [ ] IP/privacy-risici er vurderet.
- [ ] Ændringer er opdelt i før kode, prototype, senere og fjern.
- [ ] JSON-blokken er valid.
- [ ] Ingen kodeimplementering er påbegyndt.
