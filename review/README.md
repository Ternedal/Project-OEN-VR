# Reviewflow

1. Claude læser `00_READ_ME_FIRST.md` og bruger `01_PROMPT_FOR_CLAUDE.md`.
2. Det rå review gemmes i `CLAUDE_RAW_REVIEW_PLACEHOLDER.md` eller erstatter filen som `CLAUDE_RAW_REVIEW.md`.
3. Hvert `CR-xxx`-punkt behandles i `RESPONSE_MATRIX.md`.
4. Accepterede ændringer opdaterer specs, ADR-log og backlog før implementering.
5. Nye tekniske påstande kræver dokumentation eller prototypeevidens.
