# Sikkerhed og privacy

Dette er et privat hobbyprojekt med lav trusselsmodel, men følgende må aldrig committes:

- private billeder, stemmeoptagelser, navne eller andre personaliseringsassets,
- signing keys eller keystores,
- service secrets,
- rå voice logs,
- adgangstokens.

Photon App ID kan befinde sig i klientkonfigurationen, hvis tjenestens egen model forventer det, men administrative secrets må ikke. Rapporter fejl privat til repositoryejeren i stedet for i offentlige issues.
