# Diagrammer

Mermaid-kilder til review og senere dokumentgenerering:

- `system_context.mmd`: klienter, Photon, saves og personalisering.
- `network_authority.mmd`: coordinator, klientauthority og coop-objekter.
- `gameplay_state_machine.mmd`: top-level scenarieflow.
- `build_pipeline.mmd`: fælles kode til Q1/Q2/Q3-profiler og release candidate.

Diagrammerne er konceptuelle og skal opdateres, når M0/M2-prototyperne giver faktisk evidens.
