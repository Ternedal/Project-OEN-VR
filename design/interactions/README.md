# Interaction design briefs — PROJECT ØEN

Denne mappe ejes af ChatGPT og indeholder **player-experience/specification handoffs** til Claude.

Briefs beskriver:

- hvad spilleren skal opleve
- begge spilleres roller
- success/partial/fail-forward
- feedback
- assets/audio/copy IDs
- comfort/accessibility
- acceptance criteria

De beskriver **ikke** Unity-arkitektur, komponentvalg, scripts eller prefabstruktur.

## Regel

Et brief må ændres, når playtestdata viser at oplevelsen er forkert. ID'er og cross-document refs skal opdateres sammen med ændringen.
