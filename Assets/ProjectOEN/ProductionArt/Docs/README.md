# Project ØEN Production Art

Generated from the canonical 148-row asset master. Every listed state/variant is exported as an individual Unity-importable file.

- Separate sprites: **206**
- Separate world meshes: **134**
- Shared stylized Quest-friendly materials/textures: **11**
- Source: `tools/generated_art/asset_master.csv`

The generated art deliberately uses coherent handmade wood/rope/tarp/metal/stone materials, diegetic-first UI, warm camp accents and cool storm accents. No Hunger/Thirst HUD assets are generated.
