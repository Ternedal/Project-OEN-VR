# Konfigurationsreferencer

Denne mappe indeholder reviewbare projektindstillinger, før selve Unity-projektet oprettes.

- `UNITY_PROJECT_SETTINGS_CHECKLIST.md`: fysisk valideringsliste til M0.
- `GITHUB_LABELS.yml`: anbefalede labels.
- `PULL_REQUEST_TEMPLATE.md`: portabel reference til GitHub-skabelonen.
- `.gitignore_additions.txt`: private og buildrelaterede ignore-regler.

Endelige Unity package locks og platformprofiler må først committes efter fysisk Quest 1/2/3-test.
