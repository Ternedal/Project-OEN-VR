## Purpose

These are **source/reference sheets**, not finished 3D assets. They establish:

- approximate scale
- silhouette intent
- required state variants
- broad interaction/readability zones
- visual language shared across props

## QA

The concept family was designed to be readable against the project's dark neutral review background and to reuse the established palette and shape language.

Before runtime acceptance, Claude still owns:

- actual 3D/model representation
- collider/grab geometry
- world scale adjustment after device test
- material/shader
- LOD/performance
- Quest readability

If a later 3D source materially changes silhouette/state readability, the source handoff should be re-reviewed against these sheets.
