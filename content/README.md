# PROJECT ØEN content source

Denne mappe ejes af ChatGPT og indeholder **authoring/source content**, ikke Unity-runtime implementation.

- `actions/` — action-card/source semantics
- `events/` — event authoring source
- `localization/` — spillerrettet source copy
- `personalization/` — neutral profile/source contracts only; private files må ikke ligge her
- `proposals/` — maskinlæsbare forslag, som **ikke er canonical**, før den relevante beslutning er accepteret

## Balance

Source-filer med `balanceStatus` eller `status=proposal` må ikke bruges som bevis for endelig balance/scope. M3/M4/M-Pre/OQ evidence bestemmer de relevante værdier/beslutninger.
