# Gate fra review til implementering

Implementering må starte, når:

1. Claudes review er gemt med stabile `CR-xxx`-ID'er.
2. Alle BLOCKER/HIGH-punkter har en disposition i response matrix.
3. Accepterede ændringer er indarbejdet i berørte specs og ADR-log.
4. M0-scope og package-spike er opdateret.
5. Der er ingen uafklaret konflikt om netværkstopologi eller save-authority. (Quest 1-lanen er afklaret 2026-08-08: droppet.)
6. Første tekniske branch oprettes fra grøn `main`.

Dette er en dokumentationsgate, ikke et krav om at alle MEDIUM/LOW-kommentarer lukkes.
