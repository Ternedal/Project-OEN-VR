# Scope freeze for review baseline

Følgende er frosset, indtil Claude-reviewet er behandlet:

- præcis to spillere,
- Stormnatten som første scenario,
- 30-45 minutters mission,
- Quest 2-baseline,
- Quest 3/3S gameplayparitet,
- controllerbaseret VR,
- ingen open world eller persistent base,
- ingen direkte spillersabotage,
- original IP.

Claude må udfordre punkterne, men ændringer kræver ejerbeslutning og ADR.

**Opdateret 2026-08-05 (DP-001):** Quest 1 legacy-test er fjernet fra frysningen ved ejerbeslutning, jf. ADR-019. Mission-længden 30-45 minutter gælder Release 1 (M5), jf. ADR-022.
