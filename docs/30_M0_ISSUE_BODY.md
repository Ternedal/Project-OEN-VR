# M0: Bevis engine-baseline og fælles Quest 2/3 platformlane

## Formål

Reducer den største tekniske risiko, før gameplay- og contentproduktion begynder.

## Definition of done

- Engine-baseline-gaten (ADR-020, `docs/06` §3) er bestået, og minimal build starter fysisk på Quest 2 og Quest 3.
- Q2-Q3 kan forbinde i privat Photon-session med Fusion 2.1.
- Head/hands replikeres stabilt.
- Begge spillere kan løfte og snap'e samme kinematic coop-objekt 10/10 gange.
- Quest 2 og minimal Q3-scene holder 72 Hz.
- Package-, graphics API-, manifest- og protocolmatrix dokumenteres.
- Resultatet er eksplicit `GO`, `REDESIGN` eller `DROP_Q1_RUNTIME`.

## Ikke i scope

- Stormnatten-content.
- Art pass.
- Personalisering.
- Meta Platform SDK-integration.
