# Accepted baseline v2.0

Denne baseline er klar til eksternt Claude-review, men ikke til produktion.

Den indeholder produktkrav, GDD, Stormnatten-scenarie, teknisk arkitektur, multiplayer, platformprofiler, save/data, UX, art/audio, roadmap, QA, risici, 108 backlogopgaver, schemaer, eksempeldata og reviewflow.

Reviewet er gennemført (review 1.0) og de tre blockers er dispositioneret i DP-001, se `docs/32_DECISION_PACKAGE_DP-001.md` og ADR-019 til ADR-022.

Næste autoriserede handling er **M-Pre** (kernehypotese-gate, ADR-021). M0-platformspiket må først begynde, når M-Pre er grønt.
