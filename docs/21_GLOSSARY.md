# Ordliste

- **Action-zone:** Lille scene/område hvor en konkret opgave gennemføres.
- **Authority:** Hvilken klient/systemdel der må ændre en netværksstate.
- **Buildprofile:** Konfiguration for Quest 2 eller Quest 3 med samme gameplaykode.
- **Compatibility hash:** Hash af network protocol, content og schema brugt før sessionstart.
- **Coordinator:** Logisk authority for scenariofase og kritisk state i Shared Mode.
- **Delayed event:** Konsekvens planlagt nu, men udløst i senere fase/dag.
- **Diegetisk UI:** Information vist som del af spilverdenen.
- **Fail-forward:** Fejl skaber omkostning/ny situation frem for total nulstilling.
- **Gift build:** Privat, personlig første release.
- **Legacy lane:** Historisk begreb for det reducerede Quest 1-buildspor. Droppet 2026-08-08 (`DROP_Q1_RUNTIME`); indgår ikke i aktive planer.
- **MVP:** Mindste komplette produkt, her Stormnatten.
- **PersonalizationProfile:** Data/assets til privat tilpasning.
- **Quest 2 baseline:** Device der bestemmer performance og gameplaybudget.
- **Shared Mode:** Photon Fusion-topologi med delt state authority mellem klienter.
- **Vertical slice:** Kort, kvalitetsrepræsentativ gennemskæring af hele spilflowet.
