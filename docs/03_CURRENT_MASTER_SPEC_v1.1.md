# Arkiveret master-specifikation v1.1

Dette filnavn bevares for sporbarhed, fordi tidligere handoff-versioner og reviewnoter kan referere til det.

Version 1.1 var den første samlede GDD/tekniske plan, der fastlagde:

- Quest 2 som primær udviklingsplatform,
- Quest 1 som legacy-testplatform,
- Quest 3/3S som fuldt understøttede enhanced-platforme,
- to-spiller-scenariet Stormnatten,
- Unity/OpenXR/Photon-retningen,
- roadmap og QA-gates.

**v1.1 er ikke længere source of truth.** Indholdet er udbygget og opdelt i de autoritative v2.0-kapitler, som er indekseret i [`../PROJECT_OEN_MASTER_HANDOFF_v2.0.md`](../PROJECT_OEN_MASTER_HANDOFF_v2.0.md).

Den oprindelige PDF/DOCX-reference ligger i den komplette downloadable handoff-pakke, men bør kun bruges til historisk sammenligning.
