# Kort handoff til Claude

Læs først `../01_PROMPT_FOR_CLAUDE.md`.

PROJECT ØEN er et originalt, to-spiller VR-overlevelsesspil med Quest 2 som baseline og Quest 3/3S som enhanced-platforme. (Quest 1 udgået 2026-08-08, `DROP_Q1_RUNTIME`.) Første scenario, Stormnatten, varer 30-45 minutter og kombinerer fælles planlægning, fysisk samarbejde og forsinkede konsekvenser.

Reviewets vigtigste opgave er at afgøre, om produktet, netværksmodellen og scope kan realiseres af én hobbyudvikler uden at overdesigne før M0-M3 er bevist.
